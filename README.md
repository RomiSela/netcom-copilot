# Netcom Service Co-Pilot

Prototype for the Sumit AI home assignment: a real-time AI co-pilot for Netcom's service center.

- **Prototype:** `index.html` — sign in with `1` (agent) or `2` (contact-center manager).
- **Brief:** `netcom-brief.html` — findings, flow, product decisions and build approach.

Single-page React app (React 18, Tailwind CSS, Lucide, Recharts from CDN). Netcom's systems are mocked behind an API layer that follows the assignment's integration spec. CRM logs are saved in the viewer's browser.
